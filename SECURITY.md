# Security policy

Please do not report security vulnerabilities in public issues. Instead, report them privately through
[GitHub's private vulnerability reporting](https://github.com/martinporoli/fhirplace/security/advisories/new).

Include a description of the issue, the affected version, and steps to reproduce it if you can. You will get an answer
as soon as possible.

fhirplace has not reached 1.0, so fixes are made only in the latest release.
