# fhirplace-r5-all

Depends on the core and every resource module. Convenient for tools that handle any resource type, such as generic
converters; applications that serve or use a few resource types should depend on those modules instead.

```xml
<dependency>
    <groupId>se.poroli.fhirplace</groupId>
    <artifactId>fhirplace-r5-all</artifactId>
    <type>pom</type>
</dependency>
```
